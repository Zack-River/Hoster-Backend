Roles (Simplified)
1) Unit Owner (Host)

Manages listings, calendar, guest messages, and requests services.

2) Service Provider (Cleaning + Maintenance)

Receives service requests, schedules jobs, completes tasks, uploads proof, and manages services offered.

4) How “Requests Inside the App” Works (Single Flow)
Request Lifecycle (simple statuses)

REQUESTED

ACCEPTED

IN_PROGRESS

COMPLETED

CANCELED

Host → Provider flow

Host chooses a provider (from Cleaning Services screen)

Host taps Request Service

Choose:

Service type (Cleaning / Maintenance)

Listing

Date/time

Notes + access info (lockbox code / instructions)

Provider gets in-app request

Provider Accepts/Declines

If accepted:

Status → IN_PROGRESS → COMPLETED

Provider uploads proof (photos + checklist)

Host confirms completion (optional in MVP)

5) Update Your Current “Cleaning Services” Screen

6) Add “Automation” in Settings (Host only)

Settings → Automation includes:

Auto check-in message

Auto checkout thank-you

Cleaning/service automation:

Toggle: Auto request service on checkout

Choose preferred provider

Choose default time window

Provider does NOT see guest messaging automations.
